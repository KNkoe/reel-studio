# Rules for agents in this repo

- This repository is public. No personal details, client names, private screen content or
  footage in commits, commit messages, issues or history notes.
- The author's own video style (graphics, screen recordings, assembly) is private and lives
  outside this repository. Never add its code, stills or description here, in a commit message
  or in an issue.
- For any video edit, follow `skills/panel-reel/SKILL.md` and read `docs/PREFERENCES.md`.
- This repo is the only home of the editing skill. Edit it here; never copy it elsewhere.
- Never commit footage, renders, `projects/`, models, `.env` files or signing settings.
- `apps/clapless` is a separate repository linked here: commit its changes there.
- After changing the style, update the skill or preferences and add a dated entry to
  `docs/HISTORY.md`.
- After changing scripts, run `bash scripts/setup.sh --test`.
- Do not commit or push unless asked.
